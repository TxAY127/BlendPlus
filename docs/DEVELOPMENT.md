# 实现说明

## 文件布局

```text
src/BlendPlus/             WinForms 界面、资源安装、着色器生成与菜单安装
assets/                   本项目编写的 QML 辅助逻辑及旧补丁迁移文本
tests/                    使用模拟 QML 模块的安装与恢复测试
scripts/                  Windows 本地构建、测试、打包
.github/workflows/        CI 与标签触发的草稿预发布
docs/                     实现、验证及发布说明
artifacts/                生成产物，已从 Git 排除
```

## 工作方式

`Engine.Detect` 从路径缓存、运行进程、标准安装目录、注册表和快捷方式发现剪映；缓存可在便携版关闭后保留它的路径。安装和恢复会先检查剪映是否仍在运行。

`Engine.Validate` 检查本机混合资源结构。安装时复制本机正片叠底资源，替换 GLES 片元着色器中的混合函数，并在 `MixMode.json` 添加项目拥有的条目。原始声明、采样坐标、投影坐标及宿主透明度转换保留。新增文件使用 `blendplus_v1_` 前缀和 `.blendplus-owned` 标记。

所选安装目录与当前用户共享混合资源可能同时被修改。资源列表有备份；资源安装失败时会尝试恢复快照。恢复时移除本工具的条目并保留其他条目。

`MenuExtension` 对已适配的外部 Qt Graphical Effects 模块插入项目 QML 辅助逻辑，取消 `qmldir` 中的内置资源优先项，使外部文件有机会加载。辅助对象查找混合控件，将 `maxVisibleItem` 设为 8。滚轮交互依赖宿主控件，尚未确认实际效果。

菜单安装单独保存快照并尝试回滚。**混合资源安装与菜单安装不是跨阶段原子事务**：菜单安装失败时，前一步的混合模式可能已经安装。应保留错误信息，关闭剪映后使用“恢复”或重新安装。

## 本机状态

```text
%LOCALAPPDATA%/BlendPlus/installations.json
%LOCALAPPDATA%/BlendPlus/Backups/<资源目录哈希>/
```

路径缓存含本机安装位置；备份含本机资源内容。二者不应上传仓库或随发布包分发。旧版迁移文本只用于识别此前项目注入的辅助代码。

## 构建

主入口是 `MainForm`，源码使用 .NET Framework C# 编译器支持的语法。`scripts/Build.ps1` 直接调用系统编译器并嵌入三个项目资源，不下载依赖。`src/BlendPlus/BlendPlus.csproj` 提供 Visual Studio / MSBuild 项目入口。

自动测试包括混合资源安装、重复安装、恢复、其他条目保留、路径记忆与投影坐标保留，以及模拟菜单模块的迁移、重复安装与恢复。模拟菜单测试通过不表示剪映成功加载补丁，更不表示滚轮交互或 AE 图像一致性通过。
