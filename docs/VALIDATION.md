# 人工验证清单

本清单用于记录发布前的实际验证，不是自动测试已通过的声明。当前滚轮与多数图像行为仍待验证。

## 优先验证菜单

关闭剪映，安装或重新安装，再打开剪映的混合菜单：

- [ ] 菜单最多显示 8 行，顶部没有超出屏幕。
- [ ] 鼠标位于菜单上时，滚轮可以到达首项和末项。
- [ ] 滚动后能选择模式，收起再打开仍显示正确选中项。
- [ ] 界面缩放、不同窗口高度下仍可操作。
- [ ] 原有其他界面及阴影效果没有明显异常。

## 安装与恢复

- [ ] 关闭 9.7.1 后刷新，仍能发现路径并保持所选版本。
- [ ] 连续安装两次，没有重复菜单条目。
- [ ] 原有模式保留，新增模式各出现一次。
- [ ] 点击恢复后，新增模式移除，原有菜单和界面可用。
- [ ] 共享资源被多个安装使用时，记录受影响的版本。
- [ ] 无写入权限、资源不匹配、剪映仍在运行时，提示明确。
